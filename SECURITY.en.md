## Supported version

Focus Browser 1.0 is the currently supported release line.

## Reporting a vulnerability

Do not publish details of an unpatched vulnerability or attach private browser
data to a public issue. Until GitHub private vulnerability reporting is enabled
for this repository, open an issue containing only a request for a confidential
contact channel. Do not include reproduction steps, technical details or an
exploit. The repository owner will respond and arrange a private way to receive
the report.

In the private report, include the affected version, reproduction steps, impact
and any suggested mitigation. Never send a real browser profile, cookies,
saved passwords, tokens or crash dumps containing personal data. Reproduce with
a disposable profile whenever possible.
